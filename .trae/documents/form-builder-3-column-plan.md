# 流程表单编辑器三栏布局重构 Spec

## Why
当前的表单配置器（`FormBuilder.tsx`）是一个自上而下的列表结构，配置项与展示混杂在一起，不便于管理复杂的长表单。用户希望将其重构为类似飞书审批的“左中右三栏布局”（左侧控件库、中间预览画布、右侧属性配置），以提供更直观、更专业的“所见即所得”表单设计体验。

## What Changes
- **状态扩展**：在 `FormBuilder.tsx` 中引入 `selectedFieldId` 状态，用于记录当前在中间画布中被选中的字段。
- **布局重构**：将整个组件的返回结构划分为 Flex 布局的三个部分：
  - **左侧 (控件库)**：展示所有支持的字段类型按钮（如单行文本、数字、日期、人员等），点击即可添加到中间画布。
  - **中间 (预览画布)**：按顺序渲染已添加的字段（模拟真实表单的 UI，如显示带边框的占位输入框）。点击某个字段容器可将其选中（高亮边框），选中时显示删除按钮。
  - **右侧 (属性配置)**：当有字段被选中时，在此处集中渲染该字段的所有配置项（字段名称、是否必填、提示语、默认值、单位等），实时同步修改到中间画布。

## Impact
- Affected specs: 表单字段定义（Form Configuration）、页面布局交互。
- Affected code: `src/pages/Processes/components/FormBuilder.tsx`（可能需要内部拆分或重写渲染逻辑，但不影响外层 `Editor.tsx` 的数据流转）。

## MODIFIED Requirements
### Requirement: 三栏式表单设计器布局
系统应该提供专业的三栏式表单设计环境，实现控件选择、预览与配置的视觉分离。

#### Scenario: Success case
- **WHEN** 用户进入“表单配置”选项卡
- **THEN** 页面呈现三列：左侧为固定宽度的控件按钮列表，中间为空白的表单预览区，右侧提示“请在画布中选择字段”。
- **WHEN** 用户点击左侧的“单行文本”按钮
- **THEN** 中间画布底部出现一个新的文本字段模拟块，且该块被自动选中（边框高亮）。
- **WHEN** 该块被选中
- **THEN** 右侧属性面板立即出现“字段名称”、“提示语”等输入框；用户在右侧修改名称时，中间画布的对应块实时更新显示。
- **WHEN** 用户点击选中块上的“删除”图标
- **THEN** 该字段从画布中移除，右侧面板恢复为空白提示状态。
