# 动态表单配置属性面板重构 Spec

## Why
目前流程中心的“表单配置”面板中，所有的表单控件（无论文本、单选、日期等）点击后右侧展示的属性配置都是相同的“一刀切”样式。在标准的工单流程系统中，右侧属性面板应当是高度动态和数据驱动的：需要区分“通用基础属性”（如字段名称、必填、描述）、“专属动态属性”（如单选的选项列表、金额的单位）以及“高阶业务属性”（如根据其他字段的值动态显隐）。

## What Changes
- 重构 `FormField` 接口定义，扩充通用属性（如 `description`）、专属属性（如 `options`）和高级属性（如 `visibleCondition`）。
- 改造 `FormBuilder.tsx` 右侧的属性面板（Property Panel），将其划分为“基础属性”、“专属属性”和“高级配置”三个折叠面板或区块。
- 实现专属属性动态渲染逻辑：例如当选中单选（`radio`）或多选（`checkbox`）时，渲染一个可以动态增删改查的选项列表编辑器。
- 实现高阶业务属性（动态显隐）逻辑：允许用户配置当前字段是否依赖于前方另一个字段的值（例如：当“故障类型” === “硬件” 时显示）。
- 改造中间的画布（Canvas）渲染，使其能正确渲染上述新增的选项列表，并在具有动态显隐条件的字段旁添加标识。

## Impact
- Affected specs: 表单字段定义（Form Configuration）、动态属性渲染。
- Affected code: `src/pages/Processes/components/FormBuilder.tsx`

## ADDED Requirements
### Requirement: 动态专属属性与显隐逻辑配置
系统应该允许用户根据不同的表单控件配置其专属的动态属性，并支持配置字段间的动态显隐逻辑。

#### Scenario: Success case
- **WHEN** 用户在表单中添加了一个“单选”控件并选中它
- **THEN** 右侧属性面板的“专属属性”区域将出现“选项管理”，允许用户添加如“选项A”、“选项B”等具体选项。
- **WHEN** 用户在画布中添加了另一个文本字段，并在高级配置中设置“显示条件：依赖于【单选字段】===【选项A】”
- **THEN** 该配置将被保存到 `formConfig` 中，且画布上该文本字段会展示一个“条件显示”的标识角标。
