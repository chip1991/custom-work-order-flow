# 大模型测评平台 V2 Spec

## Why
用户需要一个具备模型中心、题库中心和测评中心三个一级模块的大模型测评平台。该平台能够支持配置大模型接口和多轮对话题目，并且可以调度多个大模型进行并发测试，横向对比模型回复内容和首字响应时间、生成速度等核心指标。

## What Changes
- 在现有的 `frontend` 和 `backend` 目录下开发大模型测评平台。
- **前端部分**：
  - 构建系统整体布局：侧边栏导航（模型中心、题库中心、测评中心）及主内容区。
  - 模型中心：模型列表、新增/编辑模型表单（支持设置 provider, baseUrl, apiKey 等）。
  - 题库中心：题目列表、对话编排页（动态增减系统、用户和助手的消息）。
  - 测评中心：测评任务列表、创建任务表单（多选模型和题目）、测评详情与对比页（SSE 实时流式更新各个模型的回复与指标）。
- **后端部分**：
  - 搭建基于 Node.js/Express 的 RESTful API 和 SSE（Server-Sent Events）接口。
  - 使用 SQLite 数据库存储模型配置、题目、任务及测评结果数据。
  - 实现基于并发控制的测评执行引擎，支持并发请求不同大模型，采集耗时与 Token 使用量指标。

## Impact
- Affected code: `/frontend` 和 `/backend` 目录下的相关文件。

## ADDED Requirements
### Requirement: 模型管理
支持大模型的增删改查，记录模型的厂商、URL、API Key 和启用状态。

### Requirement: 题库与对话编排管理
支持题目的增删改查。针对某个题目，可以配置多轮对话的上下文。

### Requirement: 测评任务调度与实时对比
支持选择多个模型和多个题目发起测评任务。任务提交后，系统自动发送请求给模型，前端通过 SSE 接收并展示打字机效果及生成速度、响应时间等指标。
