# 物业工单流程管理功能 Spec

## Why
为了满足物业管理场景下的工单流转需求，系统需要一个灵活的流程管理功能。该功能允许管理员通过可视化的方式定义工单的流转节点和规则（复用现有智能体编辑器美观的节点 UI 风格），同时支持自定义工单所需填写的字段表单，从而实现高度可定制的物业工单流转体验。

## What Changes
- 新增工单流程数据模型，支持保存流程图（节点、连线）和自定义字段表单配置。
- 新增后端 API 接口，用于工单流程的创建、读取、更新和删除（CRUD）。
- 前端新增“工单流程管理”列表页面，展示所有工单流程。
- 前端新增“工单流程编辑器”页面，基于 `@xyflow/react` 构建可视化编排界面，复用现有智能体编辑器的 UI 风格。
- 在流程编辑器中增加“表单配置”面板，支持自定义字段（如文本、下拉、日期等）。
- 在流程编辑器中增加节点属性配置，支持对工单流转节点进行自定义设置（如处理人、处理规则、超时提醒等）。

## Impact
- Affected specs: 暂无（新增独立功能模块）
- Affected code:
  - `backend/prisma/schema.prisma` (或者 `apps/api/prisma/schema.prisma`，需在实现时根据实际后端架构添加数据模型)
  - `backend/routes/work-orders.js` (或者 `apps/api/src/routes/workOrders.ts` 新增路由)
  - `frontend/src/pages/WorkOrders/` (新增前端页面目录)
  - `frontend/src/components/` (复用/提取智能体编辑器的 UI 组件)

## ADDED Requirements
### Requirement: 工单流程列表管理
系统 SHALL 提供工单流程的列表页，支持查看、新增、编辑、删除流程。

#### Scenario: 成功创建新流程
- **WHEN** 用户在列表页点击“新建流程”并输入名称
- **THEN** 系统创建一条新的流程记录，并跳转至流程可视化编辑页面。

### Requirement: 流程可视化编排
系统 SHALL 提供一个可视化的流程编辑器，支持拖拽节点和连线，用于定义工单流转路径。

#### Scenario: 成功保存流程图
- **WHEN** 用户在画布上拖拽工单节点（如：提交、审批、派单、完成），并通过连线定义流转顺序，点击保存
- **THEN** 系统成功保存当前的节点和连线数据，并提示保存成功。

### Requirement: 自定义字段表单配置
系统 SHALL 在流程编辑器中提供自定义字段表单的功能，允许为整个工单或特定节点配置所需的输入字段。

#### Scenario: 成功添加自定义字段
- **WHEN** 用户在表单配置面板中添加一个“下拉选择”字段（例如：报修类型），并配置好选项
- **THEN** 该字段配置被保存在流程数据中，并在后续工单实例化时作为表单项展示。
